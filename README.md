面向初中音乐学科的**机考模拟系统**：学生在浏览器里答题，交卷即判分，逐题出解析。前端是**纯静态单页**，把 `web/` 扔到任何静态服务器上就能用，不需要后端也能完整答题。

后端只为**排行榜**存在 —— 让所有做过题的人排在一起。连不上就退回本机榜，答题一分不受影响。

---

## 它解决什么问题

纸笔模考有三个绕不开的麻烦：判分要老师手工算、错题学生带不走、全班水平看不见。

这套东西对应的做法是：

| 麻烦 | 做法 |
|---|---|
| 判分耗时 | 交卷**当场出分**，每道题附解析和你的作答 |
| 错题记不住 | 错题进**本机错题本**（`localStorage`），下次打开还在，断网也能看 |
| 看不见整体水平 | 首页三张榜：做题榜 / 正确率榜 / 最高分榜 |

---

## 功能

- **15 题 / 15 分钟**，可跳题、可回头改、右下角倒计时
- **断点续答**：手滑关掉页面，重新进来接着答
- **音频可拖动**：听辨题给的是完整播放器，能拖进度条反复听，不是一次性播放
- **逐题解析**：交卷后每题列出正确答案、你的作答、解析
- **本机错题本**：纯前端存储，不上传任何个人信息
- **昵称 + 试题密码进入**：不填班级、不填姓名
- **iPad 竖屏 / 台前调度**适配，矮窗口自动压紧顶栏与题图

## 快速开始

### 只看界面（零配置）

```sh
cd web
python3 -m http.server 8000
# 打开 http://localhost:8000
```

`web/` 目录自带一套示例题库，直接就能走完整个流程。

### 带上排行榜

```sh
cd server
pip install fastapi uvicorn
uvicorn main:app --host 0.0.0.0 --port 8001
```

再把前端里的接口地址指过去即可。**后端挂了不影响答题**，只是排行榜会退化成「本机榜」。

## 目录结构

```
web/
  exam.html        考场 / 答题卡 / 成绩页 / 排行榜，全部在这一个文件里
  bank.js          题库（题目、选项、解析、音频路径）
  questions.json   题库的另一份数据源
  media/
    audio/         听力与听辨素材
    img/           识谱、乐器配图
server/
  main.py          FastAPI + SQLite，两个接口
题库/               出题源文件与说明
tools/              辅助脚本
```

---

## 后端接口

只有两个：

| 方法 | 路径 | 作用 |
|---|---|---|
| `POST` | `/api/submit` | 交一条答卷记录 |
| `GET` | `/api/records` | 取全部记录 |

**聚合与排序都在前端算**，所以以后想加一张新榜，只改前端，不动后端。

## 部署前必须改的三处

1. **试题密码** —— `web/exam.html` 里有一个硬编码的进入密码，部署前改成你自己的。
2. **题库内容** —— 仓库里的题目是示例，正式使用需替换 `web/bank.js` 与 `web/media/`。
3. **媒体体积** —— `web/media/` 约 55 MB（音频 43 MB + 配图 12 MB）。直接由服务器出图出音只适合小规模；面向公网多人使用时，建议把 `MEDIA_BASE` 指向对象存储 + CDN。

> `web/media/` 里的音频为教材配套素材，**版权归原出版方所有**，本仓库仅作教学演示归档，请勿商用或再分发。
