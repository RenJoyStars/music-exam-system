# 题库 JSON · 字段说明（给 Gemini）

一份 `questions.json` 装全部 10 套卷。前端只读这份文件，**加卷不改代码**。

## 一、整体结构

```json
{
  "version": "1.0",
  "media_base": "media/",
  "papers": [ { "id": "p1", "name": "第 1 套", "dur": 15, "qs": [ ... ] } ]
}
```

| 字段 | 说明 |
|---|---|
| `version` | 数据版本，改结构时递增 |
| `media_base` | 媒体根目录；日后上 CDN 只改这一个值 |
| `papers[]` | 卷数组，按 `no` 排序 |
| `papers[].id` | 卷号，`p1`–`p10`，**做主键，不能重复** |
| `papers[].name` | 显示名，如「第 1 套」 |
| `papers[].sub` | 一句话副标题（可选） |
| `papers[].dur` | 本卷时长（分钟），默认 15 |
| `papers[].qs[]` | 15 道题 |

## 二、单题字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | `p1q01` 这种，全局唯一 |
| `type` | string | 是 | `listen` 听辨 / `image` 识图 / `score` 谱例 / `knowledge` 通识 |
| `s` | string | 是 | 题干。空位固定写 `<span class="blank"></span>`，**前后不要自己加括号**，渲染时由前端换成「（　）」 |
| `o` | string[4] | 是 | 四个选项，恰好 4 个；可含 `<u>` 下划线、`<b>` 加粗 |
| `a` | int | 是 | 正确答案下标：0=A 1=B 2=C 3=D |
| `audio` | string | 否 | 音频相对路径，如 `media/audio/s1p02.mp3` |
| `au` | int | 否 | 音频秒数，用于显示总时长（现在统一 40） |
| `img` | string | 否 | 图片相对路径，如 `media/img/mz07.png` |
| `spec` | string | 否 | 简谱 SVG 字符串，**直接 innerHTML 插进题干下方**；已含调号与小节线，宽度自适应 |
| `e` | string | 是 | 解析：为什么对、错项错在哪 |
| `src` | string | 是 | 依据，如 `第三章·《天路》PPT 红字「印青曲｜藏族音调」` |

`listen` 必有 `audio`，`image` 必有 `img`，`score` 必有 `spec`，`knowledge` 都没有。

## 三、媒体约定

- 音频：`media/audio/s{册}p{PPT页}.mp3`，如 `s2p07.mp3` = 第二章 PPT 第 7 页《蓝花花》。
  - 命名故意跟着 PPT 页走，出题时能一眼回查原课件。
  - 统一单声道、22.05 kHz、截取开头（时长档位见下）。
- 图片：`media/img/mz01–mz30` 中国民族乐器，`xy01–xy19` 西洋乐器，均为透明底 PNG（可转 WebP）。

## 四、渲染要求（三条）

1. **题干里的 `blank` 必须替换成「（　）」**；「（　）」与紧跟的标点要锁成不可断行的一节，否则手机会出现「）」孤字掉行。
2. 音频播放器要能拖动进度条、能重听、不限制次数——真机考就是这样，别加「限播 2 次」。
3. 图片按容器宽度自适应，最大不超过原图尺寸，不要放大。
