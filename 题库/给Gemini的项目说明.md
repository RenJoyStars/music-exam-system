# 给 Gemini 的项目说明（长沙中考艺术检测 · 机考模拟系统）

> 这份文档是交接书。读完它，你应该能独立接手前端，不需要再问背景。
> 最后更新：2026-11-19

---

## 一、这是个什么考试

| 项 | 内容 |
|---|---|
| 考试名称 | 长沙市初中毕业生艺术考查（俗称「艺术中考」「艺术检测」） |
| 考试对象 | 长沙县湘珺未来学校 2024 级初三（2027 届），全体学生 |
| 考试时间 | 预估 **2026-12-16**（上一届 2025-12-16 考的，以此类推） |
| 考试形式 | **机考、闭卷**。音乐 + 美术**合卷**，各 15 道单选，各 50 分，共 100 分，**30 分钟** |
| 音乐题特点 | **突出聆听**：15 题里通常 9 题带音频，另有 1–2 题带图片（乐器图、剧照、谱例） |
| 组考方式 | 市级统考、人人必测；电脑随机抽题，A/B 卷混合分发 |
| 成绩构成 | 机考 90% + 平时基础指标 10%；全市按比例划 A/B/C/D |
| 教材 | 湖南文艺出版社（湘艺版）2024 新教材，七上—九上共 5 册 |

**关键背景**：这是模拟系统，不是真考试。学生**在自己家里**用手机或电脑练手，目的是提前熟悉真机考的界面和操作手感。所以——像不像真的，比功能多不多重要。

### 真机考实测行为（必须照做）

这些是从考场实拍照片和监考记录里确认的，不是猜的：

1. **可以任意跳题**，前后自由，不要求按顺序答；
2. **音频可以拖动进度条、可以反复重听、不限制次数**；
3. 有「标记本题」按钮，标记的题在答题卡上显示红点；
4. 15 题全部在一屏左栏列出答题卡，已答/当前/已标记三态分明；
5. 交卷后立刻出分。

> ⚠️ 绝对不要做「限播 2 次」「禁止拖动进度条」这类限制——真机考没有，做了会让学生误判考场规则。

## 二、产品形态（已经定下来的）

单页应用，四步：

```
选卷进入 → 15 题作答 → 交卷 → 出分 + 逐题解析
```

**已经删掉的东西**（任老师 2026-11-19 明确要求）：

- ❌ 排行榜（做题榜/正确率榜/最高分榜）
- ❌ 昵称、班级、姓名等一切个人信息采集
- ❌ 后端接口（如果后端已删，纯静态即可跑）

**当前不需要登录体系**。进入方式以任老师最新要求为准：不采集任何学生身份信息，不做成绩汇总。学生打开网页 → 选一套卷 → 直接答。

## 三、题库：这是本项目最核心的资产

### 3.1 数据文件

单个 `questions.json` 装全部 10 套卷，**加卷不改代码**。

```json
{
  "version": "1.0",
  "media_base": "media/",
  "papers": [
    {
      "id": "p1", "no": 1, "name": "第 1 套",
      "sub": "五章各 3 题 · 听辨 9 / 识图 2 / 通识 4",
      "dur": 15,
      "qs": [ { ...15 道题... } ]
    }
  ]
}
```

### 3.2 单题字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | `p1q01`，全局唯一 |
| `type` | string | 是 | `listen` 听辨 / `image` 识图 / `knowledge` 通识 |
| `s` | string | 是 | 题干。空位固定写 `<span class="blank"></span>`，**不要自己加括号**，渲染时由前端替换成「（　）」 |
| `o` | string[4] | 是 | 四个选项，恰好 4 个；可含 `<u>`、`<b>` |
| `a` | int | 是 | 答案下标：0=A 1=B 2=C 3=D |
| `audio` | string | 否 | 音频路径，如 `media/audio/s2p07.mp3` |
| `au` | int | 否 | 音频秒数（现在是 60），用于显示总时长 |
| `img` | string | 否 | 图片路径，如 `media/img/mz07.webp` |
| `spec` | string | 否 | 简谱 SVG 字符串，直接 innerHTML 插到题干下方（谱例题专用） |
| `e` | string | 是 | 解析：为什么对、错项错在哪 |
| `src` | string | 是 | 依据，如 `第三章·《天路》PPT 红字「印青曲｜藏族音调」` |

`listen` 必有 `audio`，`image` 必有 `img`，`knowledge` 两者都没有。

### 3.3 媒体素材（已经生成好了）

| 类型 | 命名 | 规格 | 数量 |
|---|---|---|---|
| 音频 | `media/audio/s{册}p{PPT页}.mp3`，如 `s2p07.mp3` = 第二章 PPT 第 7 页《蓝花花》 | 60 秒、单声道 22.05 kHz、48 kbps、响度归一 | 103 条（前四章） |
| 图片 | `media/img/mz01–mz30` 中国民族乐器、`xy01–xy19` 西洋乐器 | WebP，透明底，平均 24 KB | 51 张 |

命名故意跟着 PPT 页码走——出题时能一眼回查原课件，**不要改名**。

体积参考：一套 9 条音频约 3.2 MB，整套图片 1.2 MB。播放器是流式加载，首播延迟约 1 秒，不需要预下载整包。

### 3.4 题库怎么来的（决定了内容边界）

出题有两条硬规则，你改界面时可以不知道，但**不要改题目内容**：

1. **章节分组完全按学生手上的《复习资料·学生版》**。注意：学生版把《唱脸谱》《长江之歌》《野蜂飞舞》《青少年管弦乐队指南》四首放在**第二章**（教材上它们属于第四单元）——这是已经印发给学生的版本，**以学生版为准，不要纠正**。
2. **歌曲类知识只取自五章复习 PPT 的红字**——那是学生课上抄的笔记，考的就是他们抄过的东西，绝不超纲。

## 四、界面规范（视觉已经定了，别自己发挥）

### 4.1 配色

| 用途 | 色值 |
|---|---|
| 页面底 | `#F5F8FC` |
| 卡片 / 内容区 | `#FFFFFF` |
| 主文字 | `#1E2A38` |
| 次要文字 | `#5B6B7C` |
| 重点色（淡蓝） | `#DCEBF9` |
| 选中色（深蓝） | `#1A5DA8` |
| 深蓝（标题/强调） | `#123F73` |

### 4.2 答题卡三态（学生最常看的地方，必须一眼分清）

| 状态 | 底 | 字 | 边框 |
|---|---|---|---|
| 未答 | `#F1F6FC` | `#4D6076` | 淡蓝细边 |
| 已答 | `#DCEBF9` | `#123F73` 加粗 | 深蓝 45% |
| 当前题 | `#123F73` | 白色 | 无 + 投影 |
| 已标记 | 右上角红点 | | |

### 4.3 字号与断点

- 题干：桌面 20px / 手机 16px；选项 19 / 16；答题卡格 19 / 15
- 断点 900px 以下：侧栏折到顶部、答题卡横排 6 列

### 4.4 中文排版三条硬要求

1. 题干里的「（　）」和紧跟的标点（。，、；）要锁成不可断行的一节，否则手机会出现「）」孤字掉行；
2. 按钮、选项卡里的中文不要从词中间折断；
3. 长题干宁可手动断行加缩进，也不要让它自己折得难看。

## 五、技术约束

| 项 | 要求 |
|---|---|
| 技术栈 | **原生 HTML / CSS / JS**，单页即可 |
| 禁止 | **任何 CDN 依赖**（Vue/React/Tailwind/Google Fonts 全部不行）——学校机房可能只有内网，CDN 挂了就是白屏 |
| 字体 | 系统字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif` |
| 数据 | 读本地 `questions.json`，不要硬编码题目 |
| 后端 | **当前不需要**。纯静态能跑完整个流程 |
| 部署 | `exam.renqiaoyi.cn` → 43.139.116.30，nginx 静态托管 + Let's Encrypt |
| 服务器带宽 | 上行 3–4 Mbps，是全案唯一硬约束。别做「进页面预加载 10 套音频」这种事 |

### 可选功能（做不做都行）

- 断点续答：把作答进度存 `localStorage`，误关网页重开能接着答（真机考没有，但家里练习很实用）；
- 交卷前二次确认（还有 N 题未答）；
- 成绩页「再来一套」——直接回选卷页。

## 六、绝对不要做的事

1. ❌ 加排行榜、昵称、班级、姓名、学号——**一个都不要**，这是任老师明确删掉的功能；
2. ❌ 限制音频播放次数、禁止拖动进度条；
3. ❌ 引入任何 CDN 资源；
4. ❌ 改题目内容（题干、选项、答案、解析）——这部分由 WorkBuddy 那边出，改界面时原样渲染即可；
5. ❌ 改媒体文件名（`s2p07.mp3` 这种命名是对着 PPT 页码的，改了就对不上源）；
6. ❌ 把图片放大到超过原图尺寸——乐器原图只有 160–700px 宽，放大只会更糊。
